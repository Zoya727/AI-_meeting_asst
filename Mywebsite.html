Issue #02 · The problem

Meetings end. Decisions vanish.

Project teams talk for an hour and leave with scattered notes. Nobody is sure what was agreed, who owns what, or what is still open.

3 gapsLost decisions, unclear owners, and missed deadlines are what raw notes usually hide.

How Generative AI helps. A large language model can read messy notes and rewrite them into a fixed structure: summary, decisions, action items and open questions.

The risk is that it also invents details. So every prompt tells the model to use only the notes, and every output is verified by a person.

Issue #05 · The takes

Five prompts, five takes

Each take shows the first attempt, the improved prompt, and what changed in the output.

Zero-shot Take 1

Initial prompt

Summarise these meeting notes.

Improved prompt

Summarise the notes below in up to 5 bullets under 100 words. Neutral tone. Use only facts present in the notes.

Result: shorter, and no invented context.

Role-based Take 2

Initial prompt

What was decided?

Improved prompt

Act as a technical meeting secretary. List only confirmed decisions with a one-line reason. Put tentative ideas under Open questions.

Result: unconfirmed ideas stopped appearing as decisions.

One-shot Take 3

Initial prompt

Give action items.

Improved prompt

Extract action items as Task | Owner | Deadline. Example: Prepare slides | Riya | Friday. If missing, write "Not specified".

Result: consistent table, no made-up deadlines.

Few-shot Take 4

Initial prompt

Write minutes from these notes.

Improved prompt

Using the two examples above (Summary, Decisions, Action items, Open questions), convert the new notes into the same format.

Result: same four sections on every run.

Contextual and iterative Take 5

Initial prompt

Make this better.

Improved prompt

Context: 4-person student project sync on 18 Nov. Tighten the action items, flag missing deadlines, and draft a short recap for absent members.

Result: after two follow-up rounds, the minutes became a usable recap with flagged gaps.
